# Context Engine

This repository contains the **Context Engine** that makes Kite so powerful. 

---

1. Codebase indexer
2. Relational versioning & knowledge chains 
    1. Update state
    2. Extend state
    3. Derive state
3. Temporal grounding (a.k.a Time-stamping)
    1. Document date
    2. Event Date — for us this could mean tracking who made what change when
4. Hybrid search strategy
    1. Semantic Search — HelixDB
    2. Ripgrep or faster — find original source after first hit
